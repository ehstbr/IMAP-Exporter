# Ícones incluídos

Este diretório contém um tema `hicolor` mínimo com ícones SVG simbólicos
criados para o IMAP Exporter. Eles são carregados localmente pelo GTK, podem
ser recoloridos pelo tema claro ou escuro e não exigem a instalação de um
pacote de ícones no sistema.

Os arquivos fazem parte deste projeto e são distribuídos sob a mesma Licença
MIT descrita no arquivo `LICENSE`.
